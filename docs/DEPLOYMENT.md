# Публикация ПИРОФЛЕКС на GitHub Pages

## Автоматическая публикация

`.github/workflows/pages.yml` собирает статическую версию при каждом изменении `main` и при ручном запуске Actions. Результат публикуется как GitHub Pages artifact по адресу `https://gevget.github.io/pyroflex/`.

## Что входит в сборку

`node tools/build-pages.mjs` переносит активные русские и английские страницы, страницу МК101, продукты, локальные стили и скрипты, шрифты, используемые изображения и PDF-документы из каталога. Сборка не копирует исходный архив выгрузки, Tilda runtime, рабочие скриншоты и печатные макеты. Для каждого сайта сохраняются относительные адреса, поэтому проект работает под подпутём `/pyroflex/`.

Добавляются:

- манифест устанавливаемого веб-приложения и значки ПИРОФЛЕКС;
- service worker с офлайн-копиями страниц и основных стилей;
- сетевой режим для PDF, чтобы браузер не помещал крупные документы в офлайн-кеш;
- локальная страница 404 и `.nojekyll`.

## Локальная проверка сборки

```powershell
node tools/build-pages.mjs
node tools/serve-local.mjs --root dist --port 4174
```

Без аргументов `tools/serve-local.mjs` запускает исходный сайт на порту `4173`. Сервисные worker-ы требуют HTTPS или `localhost`; открытие HTML через `file://` отключает PWA-возможности.
