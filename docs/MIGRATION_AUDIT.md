# Аудит миграции ПИРОФЛЕКС

## Исходные материалы и резервная копия

- В качестве визуального и контентного ориентира сохранён `reference.html` с его выгруженными локальными материалами (`assets/original-runtime/`, `assets/original-media/`, исходные файлы шрифтов).
- В исходной главной зафиксировано 41 экспортное секционное представление и 12 артбордов с координатами и отдельными адаптивными правилами. Это инвентарные показатели экспорта, а не целевая HTML-архитектура.
- Исходный набор содержит фото, растровые рендеры продуктов и систем, изображения сертификатов, графику рейтингов/показателей, логотип и Montserrat. Продуктовые сцены — готовые растровые рендеры; признаков интерактивного WebGL/3D-генератора для этих сцен нет.
- Исходные имена блоков и ID сохранены только в резервной reference-выгрузке для сравнения. Активный `index.html` использует самостоятельные семантические элементы и классы `pf-*`.

## Новая архитектура

Активная страница построена из header/nav, hero, введения, промышленной фотосекции, показателей, блока о компании, отдельных продуктовых композиций, раздела систем, сервиса, документов, партнёрского блока, областей применения, качества, контактов и footer. Порядок и окончательная геометрия должны сверяться с `reference.html`; разделы продуктов сохраняют индивидуальные компоновки, а не унифицируются в один шаблон карточек.

Поведение реализовано локально в `assets/site/site.js`: мобильная навигация, перемещение по горизонтальной ленте документов, диалог увеличения изображения, проверка обязательных полей и подготовка письма через `mailto:`. Серверного отправителя формы нет. Обработчик формы, мобильная навигация и просмотр изображений проверялись кликами в браузере в ходе переноса; перед релизом повторить полный перечень интеракций из исходного задания.

## Зависимости и ресурсы

- Активная версия подключает локальные CSS, JS, изображения и Montserrat. Отправка аналитики, вызовы API конструктора и внешние CDN для интерфейса не требуются.
- Сертификаты/каталог по исходным внешним адресам остаются ссылками на Яндекс Диск. Это документы, не runtime-зависимость; для офлайн-копии нужны сами разрешённые файлы.
- `privacy/index.html` — локальная временная страница. Утвердить юридический текст и политику обработки персональных данных до сбора заявок/публикации.

## Известные незакрытые критерии

Сам факт успешного локального запуска и отсутствия ошибок ресурсов не доказывает пиксельное соответствие оригиналу. Скриншот 1440 px выявил отличия hero-композиции/слоёв и отсутствующие элементы исходной навигации; значит критерий визуального совпадения и полный аудит текстов пока не пройдены. Не объявлять миграцию принятой до устранения отличий и повторной визуальной сверки при 1920, 1440, 768, 390 и 375 px, а также проверки каждого элемента взаимодействия.
