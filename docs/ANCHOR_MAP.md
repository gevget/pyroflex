# Карта семантических якорей

Переходы в активной автономной версии ведут на ID `index.html`. Якоря старого экспорта не переносятся как имена: используется назначение секции или продукта.

| Назначение | Новый URL / ID | Где используется |
|---|---|---|
| Верх страницы / логотип | `#top` | Логотип, подвал |
| Основной контент | `#main` | Ссылка пропуска навигации |
| О продукте | `#intro` | Стрелка hero |
| Продукты | `#products` | Навигация и CTA |
| Система Т | `#systems` | Основной раздел систем |
| Сервисы | `#services` | Навигация, footer |
| Документы и сертификаты | `#documents` | Навигация, footer |
| Партнёрам | `#partners` | Навигация, footer |
| Области применения | `#applications` | Footer |
| Контакты | `#contacts` | Навигация, CTA, footer |
| Пирофлекс Ультра | `#product-ultra` | Footer, карта продуктов |
| Пирофлекс База и Финиш | `#product-base-finish` | Footer, карта продуктов |
| Пирофлекс Акрил | `#product-acrylic` | Footer, карта продуктов |
| Пирофлекс Эпокси | `#product-epoxy` | Footer, карта продуктов |
| Пирофлекс Терма Ультра | `#product-therma-ultra` | Footer, карта продуктов |
| Пирофлекс Терма Эпокси | `#product-therma-epoxy` | Footer, карта продуктов |
| Система-Т Ультра | `#system-t-ultra` | Footer, карточка системы |
| Система-Т Эпокси | `#system-t-epoxy` | Footer, карточка системы |
| Пирофлекс Кабель | `#product-cable` | Footer, раздел кабельного состава |

Переходы с локальной страницы политики (`privacy/index.html`) ведут на `/` и `/#contacts`. После добавления раздела следует добавить уникальный ID, затем ссылку в навигации/CTA и повторно выполнить `node tools/audit-standalone.mjs`.
