# Шаблон продуктовой страницы

Заполнять по продуктовой карточке и согласованным официальным документам. Не подменять системные показатели параметрами отдельного материала.

Для визуальной компоновки использовать раздел «Внутренняя продуктовая страница» в [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md). Этот файл задаёт контент и порядок сведений, а не точную геометрию экрана.

## 1. Первый экран

- Надзаголовок: тип продукта / назначение.
- Название и короткое описание.
- Артикул/код, ТУ.
- Ключевые показатели в метках: предел огнестойкости, температурный диапазон, среда/категория коррозионной стойкости, срок службы, сейсмика — только если подтверждены для этого продукта.
- Банка без фона или согласованная композиция из `back/`.

## 2. Область применения

- Основание и тип защищаемого объекта.
- Условия эксплуатации, ограничения по интерьеру/наружной атмосфере.
- Отраслевые метки и пиктограммы из локального набора.

## 3. Преимущества

Короткие, проверяемые тезисы. Сохранять условия и оговорки: например, «наружная эксплуатация — совместно с ФИНИШ».

## 4. Описание материала

Основа, компоненты, вид покрытия, цвет/фактура, тара и ограничения по безопасности — по источнику.

## 5. Технические характеристики

Использовать таблицу «Параметр / Значение». Для каждого значения указать единицы, диапазон и условия, если они есть в первоисточнике.

## 6. Сертификация и документы

Показывать только реальные локально доступные документы. Каталожное упоминание стандарта не означает, что файл сертификата приложен. Список файлов и папка хранения — в `SOURCES.md`.

## 7. Расход материала

- Краткое правило/опорное значение.
- Ссылка на таблицу расчётного расхода из `tables/`.
- Указать, что фактический расход зависит от толщины, способа нанесения и технологических потерь, если это оговорено в источнике.

## 8. Технология нанесения

Подготовка основания и компонентов, условия воздуха/поверхности, оборудование и параметры, межслойная выдержка, полное отверждение, СИЗ. Не сокращать критичные ограничения.

## 9. Хранение

Температурный диапазон, срок и ограничения. Не выводить срок годности для компонентов системы по сроку отдельного материала без источника.

## 10. Сопутствующие материалы

Карточки соседних продуктов с проверенными ссылками. Грунт и финиш указывать в соответствии с конкретной системой нанесения.

## Контентный контроль перед публикацией

- Проверить, что название, код и ТУ соответствуют выбранной карточке.
- Сверить все цифры с техническим документом и актуальной таблицей расходов.
- Сохранить квалификаторы: «до», «не более», «при», «только с финишным слоем».
- Для составных систем подписывать, к какому слою относится характеристика.
- Для сертификата показывать именно файл из папки исходных документов, а не только запись из каталога.
