## Сверка СИСТЕМ-Т

Сжатый каталог содержит компактные значения для систем, которые расходятся с отдельными официальными PDF-таблицами и сводным PDF. Например, выделенная строка ПТМ 3,4 мм для СИСТЕМА-Т УЛЬТРА показывает в официальной таблице слои 2,14/2,34 кг для 90 минут; 2,86/3,13 кг для 120 минут; 3,81/4,19 кг для 150 минут. Использовать значения отдельной официальной таблицы. Перед публикацией самой страницы желательно подтвердить, что это последняя редакция расчётных документов.

В PDF систем единица расхода в заголовке сокращена до «кг», в каталоге используется «кг/м²». В MD она нормализована как кг/м² по смыслу таблицы — расход на площадь защищаемой конструкции. Сохраняйте исходный PDF рядом со страницей.
