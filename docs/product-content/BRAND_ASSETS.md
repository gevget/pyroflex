## Иконки

Папка `branding/icon/` содержит 31 SVG в тематических группах (Construction, Tools; Delivery; Energy, Renewable; Files; Interface, Essential; Money; Servers, Databases; Transportation; Weather, Climate), а также `Frame.svg` и `Frame-1.svg` в корне.

- В исходной папке 26 SVG используют штрих `#E8B54E`, ещё 5 — `#AC9354`.
- Цвет задан непосредственно в SVG; это не `currentColor`. Оригиналы остаются нетронутыми.
- Для страницы ПИРОФЛЕКС-УЛЬТРА подготовлены 31 отдельная копия в `assets/site/icons/ultra/`; все штрихи окрашены в подтверждённый пользователем цвет `#AC9354`.
- Размеры иконок на типовой странице — 36×36 px. Иконки показываются без чёрных круглых подложек. Общая библиотека и исходные SVG не меняются.
- Сохранять исходные пропорции, толщину линий и прозрачный фон. Не заменять иконки emoji и не вводить самостоятельную цветовую систему.

Для остальных внутренних страниц генератор объединяет 31 тематическую иконку Ультры с общими SVG сайта и записывает локальные цветовые наборы в `assets/site/icons/<slug>/`: `acrylic`, `base`, `cable`, `epoxy`, `finish`, `therma-ultra`, `therma-epoxy`, `system-t-ultra`, `system-t-epoxy`. Все отображаются размером 36×36 px без подложек. Для системных страниц общий набор окрашен в серый `#939393`; цвет конкретного слоя показывают его собственные изображения и ссылки на материал. Светлые иконки Акрила остаются белыми на тёмных поверхностях и затемняются CSS только на светлых участках для контраста. Для кабельных применений добавлена отдельная монохромная SVG-иконка в той же визуальной манере, поскольку в исходной библиотеке не было знака кабеля.

## Акценты каталога

Рабочие цвета продуктовых акцентов ниже подтверждены пользователем. Для Акрила сохранена предварительная визуальная оценка по каталогу; её следует сверить перед отдельной страницей продукта.

| Продукт / система | Акцент каталога |
|---|---|
| Ультра: заголовок, цифры и иконки | `#AC9354` — бронзовый |
| Акрил | нейтральный белый `#F5F5F5` по графике страницы каталога, визуальная оценка |
| Кабель | `#FF9F1C` — оранжевый |
| База | `#24AC84` — зелёно-бирюзовый |
| Финиш | `#AC55FF` — фиолетовый |
| Эпокси | `#D94E4E` — красный |
| Система-Т Ультра | `#939393` плюс цвет Ультры `#AC9354` |
| Система-Т Эпокси | `#939393` плюс цвет Эпокси `#D94E4E` |
| Терма Ультра / Терма Эпокси | белый в системных карточках каталога |

Цвет — часть идентификации направления, а не декоративная подложка по умолчанию. Не переносить цвет системы на отдельную банку или наоборот.
