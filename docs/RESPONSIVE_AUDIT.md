# Адаптивность и производительность сайта

Проверка проведена **22 ноября 2026** на локальной автономной сборке.

## Проверенные страницы

- Главная RU/EN, контакты, документы, партнёрам и сервисы RU/EN.
- Страница инженерного центра [МК101](../mk101/index.html).
- Политика конфиденциальности.
- Страницы продуктов: Ультра, Акрил, База, Финиш, Эпокси, Кабель, Терма Ультра, Терма Эпокси, Система-Т Ультра и Система-Т Эпокси.

Итого: **22 активные страницы**.

## Адаптивная проверка

Все страницы проверены на девяти ширинах/высотах окна:

| Класс экрана | Размеры |
|---|---|
| Узкий телефон | 320×740, 360×800 |
| Телефон | 390×844, 430×932 |
| Планшет | 768×1024 |
| Ноутбук | 1024×768, 1280×800 |
| Большой экран | 1440×900, 1920×1080 |

На всех **198 сочетаниях страницы и размера окна** не обнаружено горизонтального переполнения, ошибок консоли, повреждённых изображений или отсутствующих размеров изображений. После оптимизации повторно проверены все страницы на 390×844 и 1280×800; изображения принудительно декодированы в браузере.

На ширине 320 px заголовок страницы политики раньше выходил за экран. Для него уменьшен минимальный размер и включён перенос длинного слова.

- Мобильное меню ПИРОФЛЕКС открывается и закрывается.
- Мобильное меню МК101 открывается, показывает ссылки и закрывается.
- Фильтр документов ПИРОФЛЕКС по продукту «Ультра» показывает 12 подходящих документов из 48.
- На странице Ультра карусель сертификатов переключается с «01 / 03» на «02 / 03».
- Ошибок и предупреждений в консоли браузера во время повторной проверки не было.

## Оптимизация изображений

- Для 290 тегов `<img>` добавлены исходные `width` и `height`, чтобы браузер резервировал правильное место до загрузки изображения.
- Для 45 крупных изображений созданы WebP-версии. Активные страницы загружают их; исходные файлы сохранены.
- Размер обработанных исходников: **47,6 МБ**. Размер WebP-копий: **6,9 МБ**. Экономия: **40,7 МБ (85,5%)**.
- Все 45 WebP-копий имеют те же размеры по ширине и высоте, что и оригиналы.
